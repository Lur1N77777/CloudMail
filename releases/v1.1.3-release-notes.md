# CloudMail V1.1.3

V1.1.3 是面向正式公开使用的安全与发布加固版本，保持现有 Cloudflare Temp Email Worker、邮箱和管理员操作兼容。

## 重要升级提示

V1.1.2 及更早 GitHub APK 使用 Android Debug 证书；V1.1.3 起改用 EAS 私有生产证书。Android 不允许不同证书的应用互相覆盖安装，因此旧版不能直接升级到 V1.1.3。

旧版用户请按以下顺序迁移：

1. 在卸载前记录每个 Worker 的地址、前端地址、管理员密码和站点密码。
2. 在“邮箱”地址页逐个打开仍需保留的账户，复制并妥善保存邮箱凭证；也可确认邮箱地址和密码可重新登录。
3. 确认凭据已在其他安全位置保存后，卸载 V1.1.2 或更早版本。
4. 安装 V1.1.3，重新配置 Worker，并通过“凭证导入”或“密码登录”恢复邮箱账户。

不要在未保存凭据时卸载旧版。Android 卸载会删除应用本地配置。

## 本版更新

- Worker 管理员密码、站点密码、邮箱 JWT 和邮箱密码在 Android/iOS 上迁移到系统 SecureStore。
- 迁移流程先完成安全写入，再删除 AsyncStorage 中的明文；安全存储异常时保留旧数据，避免静默丢失。
- 多 Worker/多邮箱安全读取改为并行，减少启动等待；删除配置时清理不再使用的密钥。
- Worker 测试连接可准确区分站点密码、管理员密码、接口不兼容、超时、限流和 Worker 5xx。
- 移除未使用的通知、音频、视频和图片原生模块。
- 禁止通知、录音、开机启动、唤醒锁、外部存储和悬浮窗等无关 Android 权限，并关闭应用数据备份。
- 设置页新增隐私政策和使用条款入口。
- CI 增加类型、测试、Lint、生产 Web 导出、干净 Android Release、Manifest 和 SecureStore 依赖门禁。
